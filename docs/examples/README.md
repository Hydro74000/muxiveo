# Exemples hybrides

Remplacer les chemins sources et la sortie avant exécution. Les trois jobs sont
au format exact-job v1. Le fichier « season » représente **un épisode** ; la
commande `hybrid --ref-dir … --donor-dir … --export-workflow dossier` crée la
collection de jobs d'une saison. Les décalages des exemples sont illustratifs,
pas des calibrations à appliquer à des médias arbitraires.
