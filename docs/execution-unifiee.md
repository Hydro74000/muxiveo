# Exécution et journal communs

La barre située au-dessus du journal commande le panneau actif : le projet partagé entre conteneur et encodage, Hybrid Studio, ou Merge DoVi / HDR10+.

- Le bouton indique l’action : **Remux & Encode** pour le projet média partagé, hybrider un fichier ou un lot, ou fusionner les métadonnées dynamiques.
- La flèche apparaît lorsqu’une autre opération est prête. Le menu indique l’action et le projet concernés. Une entrée ouvre le panneau correspondant et lance cette opération, avec ses validations habituelles.
- Un panneau incomplet indique ce qui manque. La flèche permet toujours de lancer un autre projet prêt.
- Depuis les paramètres, les extensions ou le tableau de bord, **Choisir une opération** ouvre ce même menu.

Pendant une exécution, la navigation reste disponible. La barre conserve le traitement en cours, son étape et son annulation. Une seule opération peut être lancée à la fois. Dans Hybrid, l’analyse et les épisodes successifs appartiennent au même lot ; annuler empêche le départ de l’épisode suivant. Les erreurs restent visibles dans le journal et la barre propose une relance.

Le journal s’ouvre au lancement. Les messages portent leur origine — média, Hybrid, DoVi ou application — ainsi que l’épisode concerné pour les lots. Le filtre permet de retrouver les messages d’une opération sans effacer l’historique. Les métriques fréquentes alimentent la progression ; les sorties détaillées des outils restent disponibles dans le logging fichier verbose.

Le défilement suit les nouvelles lignes. Remonter dans le journal suspend ce suivi ; **Reprendre le défilement** revient aux messages récents. La limite de lignes configurée continue de s’appliquer.

L’habillage comprend l’en-tête de l’espace de travail, navigation regroupée, cartes, commande scindée et journal commun. Le modèle d’assemblage témoin, les options avancées et la pré-écoute restent accessibles dans les sections repliables d’Hybrid. Merge conserve le détail de ses étapes dans une section repliable. Les thèmes sombre et clair et l’échelle de l’interface restent disponibles.
